# Archived genealogy bootstrap implementations

These classes preserve historical imports and audit/reconciliation compatibility. They are not development seed entry points. The authoritative entry point is Database\Seeders\DatabaseSeeder, which consumes the normalized genealogy package. New bootstrap defaults live in AlZoubiSeedDefaults.

Archived classes:
- AlQawasmehBranchSeeder
- AlZoubiGenealogySeeder
- AlZoubiResearchContextSeeder
- AlZoubiRootVariantSeeder
- AlZoubiSharedAncestrySeeder
- BranchFounderSeeder
- BranchSeeder
- DevelopmentAdminSeeder
- FamilySeeder
- FamilyTreeSeeder
- GenealogyPeopleSeeder
- GenealogyRelationshipSeeder
- SourceSeeder
