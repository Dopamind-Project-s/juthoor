# UX-P0.9 — Baseline audit

Baseline: `main`, `327d9c55`, clean working tree; PHP 8.3.6 / Laravel 13.31. Reproduced full SQLite: 467 tests, 432 passed, 35 failed. These exact failures match the preceding phase. No evidence of an SQLite-specific environment cause; PostgreSQL comparison will be reported after verification.

## Existing architecture and observed usability problems

| Area | Existing implementation | Finding / reuse |
|---|---|---|
| Platform | SiteAdmin controllers, SiteHealthService, generic resource pages | Same management shell as families; maintenance form precedes operational work; 15 undifferentiated metrics; core health disappears behind diagnostics toggle |
| Family | FamilyDashboardService / FamilyHealthService, SelectedFamilyTree | Scoped data exists; roles see broad genealogy nav and data-quality work regardless of editorial/moderation focus; identity is a small initial rather than published branding |
| Genealogy | Record/Person/Relationship/Branch controllers, changes/diff, merge/recovery, sources | Existing integrity, comparison, self-review separation and tree actions should be reused; add filters/context rather than replacement workflows |
| Community / publishing | Entity controller + module controllers/services, Phase 4 / P0.8 views | Existing owner/subject/audience and review boundaries; entity index reveals unmanageable draft siblings and offers unsupported generic management links to news-only roles |
| Directory | MemberDirectory + DirectoryProfileController | Existing opt-in/consent/report review; surface authorized queues without copying contact fields |
| RBAC | PermissionCatalog, FamilyPermissions, FamilyPolicy, scoped assignments | Effective functional/entity grants exist; nav and quick actions largely follow membership role instead |
| Portal/domains | PortalSettings, FamilyHosts, domain lifecycle | Approved structured palette/logo are reusable; never activate domains or load custom CSS |
| Audit/maintenance | AuditLog visibility, recovery services, MaintenanceTools middleware | Preserve recording semantics and enable/disable switches; navigation currently ignores disabled tools |
| UI | layouts.management, site-nav/family-nav, Bootstrap/Juthoor tokens | Reuse entry point; introduce distinct workspace frames with shared accessible shell/components; table overflow and mobile focus need consistent handling |
